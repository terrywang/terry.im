# terry.im

`/home/terrywang`, `$HOME/terrywang` or `~terrywang` ;-)

Personal homepage of Terry Wang — styled as a terminal session transcript.

Zero dependencies. No build step. No frameworks. Just HTML, CSS, and a sprinkle of vanilla JS for the theme switcher.

Opinionated by design: KISS or nothing. If it can't be served from a single file on a Raspberry Pi, it doesn't belong here.

Self-hosted on a Pi 4 running Fedora aarch64 — because real hackers serve from `$HOME`.
